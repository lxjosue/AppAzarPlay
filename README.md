# 🎉 AppAzarPlay

Aplicación móvil desarrollada para la gestión de sorteos de manera simple, rápida y efectiva. Ideal para eventos, promociones o dinámicas comerciales.

---

## 🚀 Características

- 🎯 Creación de sorteos personalizados
- 👥 Gestión de participantes
- 🔢 Selección aleatoria automática
- 📱 Interfaz simple e intuitiva
- ⚡ Rápida ejecución y resultados inmediatos

---

## 🛠️ Tecnologías utilizadas

- C#
- .NET
